# 동네 이야기 글·댓글에 쓸 수 없는 말 (COM-03)
# - 한 줄에 하나. 제목·내용·댓글·사진 설명의 '낱말'(띄어쓰기로 나눈 덩어리) 안에 이 말이 들어 있으면 올리지 못하게 한다
# - 대소문자, 낱말 안에 끼운 숫자·기호(시1발, 씨.발, 씨~발), 흔한 바꿔 쓰기(0→o, 1→i, 3→e, 4→a, 5→s)는 풀어서 비교한다
# - 영어 금지어는 영어 낱말의 앞부분만 본다 (fucking·bitches 는 막고 Scunthorpe 처럼 가운데 든 것은 통과)
# - 띄어 쓴 것(씨 발)은 잡지 않는다. 띄어쓰기를 무시하면 '투병 신청' 같은 멀쩡한 글이 걸려서다. 이런 글은 신고로 처리한다
# - 닉네임 목록(nickname-banned.txt)보다 좁다. 글에서는 '보지(가 보지 않았다)', '씹(씹는 맛)', '새끼(새끼손가락)',
#   '꺼져(불이 꺼져)', '걸레', '호로록' 같은 멀쩡한 말이 많아서 그런 말은 넣지 않았다
# - [허용] 아래는 금지어가 들어 있어도 멀쩡한 말. 이 말을 지운 뒤에 금지어를 찾는다
# - 고친 뒤 서버를 다시 켜면 적용된다. 이미 올라간 글은 바뀌지 않는다 (신고·관리자 가림으로 처리)
# - 멀쩡한 말이 걸리면 [허용]에 넣어 주세요
