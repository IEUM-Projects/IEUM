회원 관리

회원을 찾아보고 작성 정지·강제 탈퇴를 해요. 강제 탈퇴는 되돌릴 수 없어요. 글·댓글이 모두 가려지고, 같은 이메일·카카오 계정으로는 다시 가입할 수 없어요.

    회원 정보

    최근 글

    쓴 글이 없어요.

      작성 정지

      정지하면 글·댓글·신고를 쓸 수 없어요. 로그인과 보기는 그대로예요.

      강제 탈퇴

      • 글·댓글을 모두 가려요. 동네 이야기 관리에서 하나씩 다시 보이게 할 수 있어요.
      • 같은 이메일·카카오 계정으로 다시 가입할 수 없어요. 나중에 ‘재가입 허용’으로 풀 수 있어요.
      • 이메일·비밀번호·찜·알림 같은 개인정보를 지우고, 모든 기기에서 로그아웃돼요.
      • 이메일 회원에게는 아래 까닭을 메일로 보내요.

      재가입 허용

      강제 탈퇴 때 막은 이메일·카카오 계정으로 다시 가입할 수 있게 해요. 탈퇴 상태와 가린 글은 그대로예요.
