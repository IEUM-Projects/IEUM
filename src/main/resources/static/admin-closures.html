폐업 의심 가게

행정안전부 인허가 데이터에서 폐업·휴업으로 나온 백년가게예요. 가게를 바로 숨기지 않으니, 인허가 내용과 비교해서 처리해 주세요.

확인 현황

    인허가 파일로 확인하기

    1. 공공데이터포털에서 행정안전부_식품_일반음식점·휴게음식점·제과점영업 파일데이터(CSV)를 받아요. 시·도별 파일도, 전국 파일도, zip도 괜찮아요.
    2. 아래에서 받은 파일을 한꺼번에 골라 올려요. 업종과 시·도는 파일 내용으로 알아내요.
    3. 올린 파일에 없는 시·도의 가게는 바꾸지 않아요. 한 달에 한 번쯤 새 파일로 다시 올리면 돼요.

    파일은 이 서버 안에서만 읽고, 다 읽으면 지워요.
